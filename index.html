Phân tích công nợ phải thu

Tải file “Chi tiết công nợ phải thu theo hóa đơn” (xuất từ phần mềm kế toán) để bắt đầu.
Kéo thả file Excel vào đây
hoặc bấm để chọn file (.xlsx, .xls, .csv)

Cần các cột: Tên/Mã khách hàng, Số hóa đơn, Hạn thanh toán, Giá trị hóa đơn, Số đã thu, Số còn phải thu.
Hỗ trợ cả dạng có cột “Mã khách hàng” và dạng nhóm theo dòng “Tên khách hàng: …”.
